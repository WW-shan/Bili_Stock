# 因子入门学习笔记 — 2026-04

做了几个月A股量化后,终于把"因子"这个概念理清楚了。这份文档记录了和Claude对话后内化的几个核心认知。以后脑子糊的时候翻回来看一眼。

## 一、因子是什么?

**最朴素的定义:因子 = 一个给股票打分排序的规则**。

- 输入:股票状态(价格、财报、成交量……)
- 输出:每只股票一个分数
- 用途:按分数排序 → 买高分的,不买低分的

每个因子就三件事:
1. **怎么算分**(一行pandas就能写)
2. **背后的假设**(一句人话)
3. **假设对不对**(IC验证)

### 我已经做过的三个因子

| 因子 | 打分规则 | 假设 | 实际结果 |
|---|---|---|---|
| **雪球共识因子** | 按大V持有数排名 | "多人跟=好股" | 反了 (Top30 0.7% vs Bottom30 7.5%) |
| **low_vol因子** | 1/σ_60d | "稳的长期跑赢" | 对了 (CAGR_net 13.17%) |
| **MAX因子**(待做) | −max_ret_20d | "散户追暴涨股→反转" | 待验证 |

其他所有概念(industry neutralization、z-score、quintile)都是**让分数更干净、更可比的技术细节**,不是因子本身。

## 二、IC衡量什么?

**IC = Information Coefficient = 排序准确率**(不是精确预测)

### 做法
1. 今天对N只股票按因子打分排名
2. 等k天后按真实收益排名
3. 两个排名的Spearman相关系数 = 这一期的IC
4. 10年下来有几百期 → 平均IC + ICIR(均值/标准差)

### 参考标准(量化行业)

| IC | 含义 |
|---|---|
| ≈ 0 | 纯噪声,因子没用 |
| ≈ 0.03–0.05 | 弱但真实(我的low_vol是0.0335) |
| > 0.1 | 警惕 — 可能是look-ahead或数据问题 |
| > 0.3 | 99%是bug |

### 关键一句话
IC看**排序**,不是**精确预测**。量化从不预测单只股票涨多少,只预测"这只比那只好"。

## 三、为什么固定12天调仓不是笨?

固定12天是**最干净的基线**,不是最智能的方案。

### 固定调仓的优点
- 参数少 → 不容易过拟合
- 不同因子可以公平对比
- 学术研究容易复现

### 更智能的调仓(以后可以做)
- **Buffered rebalance**: 已经在做,`keep_q=0.70`就是这个思路(分数跌破keep才换,不到阈值不动)
- **Signal-decay-aware**: 高波动期多调(信号衰减快),低波动期少调
- **Threshold-triggered**: 按分数变化幅度触发,不按时间
- **Regime-adaptive**: 下跌市多调(抢flight-to-quality的rebound),上涨市少调

### 顺序很重要
**先保证基础因子对,再加智能调仓**。不要在垃圾信号上refine。

## 四、因子怎么"挖"?—— 最重要的反直觉

**因子不是挖出来的,是想出来然后用数据验证的。**

### 死法:纯数据挖矿
生成几千个变量,全部跑IC,选最高的几个。**回测漂亮,实盘必挂**。

原因:你测了10000个假设,按纯运气也会有~100个在10年数据上假装有IC=0.03。这是p-hacking。

### 活法:行为假设驱动

先问一个问题:

> **"市场上谁在犯一个系统性错误? 这个错误会让他们愿意亏钱卖给我什么?"**

每个真实alpha背后都有**一个结构性输家**。能说出"谁在亏钱、为什么愿意亏"→ 因子就有基础。说不出 → 是噪声。

真实例子:
- **low_vol**: 机构被杠杆约束,不敢买低波动股 → 低波动股被低估
- **MAX**: 散户有彩票偏好,追昨天暴涨的股 → 高估,后续反转
- **value**: 投资者追热门故事股,忽略便宜的无聊公司
- **momentum**: 市场对好消息反应不足,涨一点但没涨够

### 工作流(明天要"挖"一个新因子)
```
1. 提假设  - "我观察到散户在___场景下总是做___,应该造成___定价错误"
2. 找学术支持  - Google Scholar/知网搜一下,90%情况有人做过
3. 写公式  - 一行pandas能算出来(复杂公式往往是过拟合信号)
4. 跑IC  - 在broad panel上看IC/ICIR
5. 结构性检查  - look-ahead? survivorship? industry concentration?
6. 稳健性  - 2015-2019和2020-2025一致吗? 不同行业都work吗?
7. 成本后  - 实际换手 × 56bp round-trip后,还剩多少?
```

## 五、散户的处境:劣势还是优势?

我担心"作为散户很难想出因子",但其实**完全相反**。

### 最重要的一句话

**你不需要"想出"新因子。学术圈已发表600+因子,一辈子用不完。**

真正拉开差距的是:
1. **会不会挑** — 哪些因子在A股、2025年、散户钱主导的背景下还管用
2. **会不会组合** — stack已有因子对冲彼此弱点
3. **会不会执行** — MDD-30%时有没有纪律不改参数
4. **有没有干净数据和QC流程** ← 这个我已经有了

Fama-French 1992发表的value+size+momentum,**30年后的今天还在赚钱**。不需要发明新东西。

### 散户 vs 机构的真实对比

| 优势 | 机构 | 散户 |
|---|---|---|
| 持仓时间 | 季度考核,拿不住 | 任意 |
| 可做的小票 | 体量太大玩不动 | 随便玩 |
| 可做的冷门 | 怕解释不清客户 | 爱咋咋地 |
| 可承受MDD | 超过-20%被清盘 | 自己扛 |

**最大的alpha源:"时间"和"冷僻"**。

### 我其实已经发现过因子

> "雪球大V的共识是contrarian的,跟着买反而亏钱"

这是一个**A股特有、学术论文没人做过**的因子。QC审计把它验证为短信号。很多PhD发paper就是这种级别的发现。我不是想不出,是**没意识到自己已经想出过**。

## 六、A股独有的因子空间

美国因子在A股一半会失效,但A股有自己的独特空间,学术研究少、竞争小。

### 散户行为异常类
- **MAX因子**(彩票偏好)— A股比美国强3-5倍
- **亏损厌恶**(浮亏被割,浮盈早卖)
- **关注度偏差**(涨停板、龙虎榜入选后被过度买入 → 反转)
- **处置效应**(卖涨不卖跌)

### 结构性规则类
- **T+1效应**(日内涨但隔夜跌的倾向)
- **ST制度**(退市风险股的系统性错价)
- **涨跌停板**(10%限制造成的信号堆积)

### 资金流类
- **北向资金**("聪明钱")
- **龙虎榜**游资席位跟随
- **大宗交易**折价率
